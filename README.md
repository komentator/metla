# Металлоискатель для Android

Это Android-приложение реализует упрощенную VLF-схему с фазовой дискриминацией:

- левый аудиоканал: TX-синус 1-16 кГц на внешний усилитель передающей катушки;
- микрофонный вход: RX-сигнал с приемной катушки через внешний предусилитель;
- цифровой lock-in детектор: каналы I/0° и Q/90°;
- ФНЧ: 13 Гц;
- правый аудиоканал: мониторный звук 400 Гц для I и 800 Гц для Q.

## Что умеет

- генерирует TX-синус на левом канале;
- читает RX через `AudioRecord`;
- выполняет синхронное детектирование I/Q;
- показывает амплитуду в dB, фазу, I/Q и RX Level;
- отображает вектор I/Q как простую фигуру Лиссажу;
- поддерживает баланс грунта: выключен, разово, непрерывно;
- формирует два тона: 400 Гц для I и 800 Гц для Q;
- поддерживает линейную и логарифмическую шкалу звука.
- имеет железный фильтр по фазовому сектору -30°...+10°: выкл., мягкий, жесткий.

## Важно по подключению

Нельзя подключать катушки прямо к телефону без внешней схемы. Микрофонный вход смартфона рассчитан на маленький сигнал и обычно имеет питание для electret-микрофона. Передающая катушка также требует внешнего усилителя: аудиовыход телефона не рассчитан на питание катушки напрямую.

Минимально нужны:

- TRRS-разъем или USB-C аудиоадаптер с микрофонным входом;
- развязывающий конденсатор последовательно с сигналом;
- резистор/делитель для ограничения уровня;
- защитные диоды или другой ограничитель амплитуды;
- общий провод катушки/схемы на GND гарнитурного входа.

Типичная распиновка CTIA/TRRS:

- Tip: левый наушник;
- Ring 1: правый наушник;
- Ring 2: GND;
- Sleeve: MIC.

Упрощенный вариант входа для экспериментов:

```text
катушка/схема -> 100 нФ -> 10 кОм -> MIC
                         |
                       100 кОм
                         |
                        GND
```

Практически лучше использовать отдельный генератор/усилитель/ограничитель, а в телефон подавать уже слабый аудиосигнал примерно микрофонного уровня. Если используется USB-C адаптер, он должен поддерживать именно микрофонный вход, а не только наушники.

Для стабильного металлоискателя катушке обычно нужен генератор/LC-контур или отдельная аналоговая схема. Приложение измеряет уже пришедший аудиосигнал, а не возбуждает катушку как полноценный прибор.

## Каналы audio jack

В этой версии принято такое распределение:

- Tip / Left: TX 1-16 кГц на усилитель передающей катушки;
- Ring 1 / Right: звук оператора 400/800 Гц;
- Ring 2 / GND: общий;
- Sleeve / MIC: RX с предусилителя приемной катушки.

На телефонах без mini-jack нужен USB-C аудиоадаптер, который поддерживает микрофонный вход и стереовыход.

## Как собрать APK

1. Откройте папку `MetalDetectorAndroid` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Нажмите `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
4. Готовый APK появится в `app/build/outputs/apk/debug/`.

## Как тестировать

1. Установите приложение на Android-телефон.
2. Подключите TX к левому каналу через внешний усилитель.
3. Подключите RX через предусилитель и защиту к микрофонному входу.
4. Разрешите доступ к микрофону.
5. Начните с TX уровня 5-15%.
6. Нажмите `Калибровка`, держа катушки вдали от металла.
7. Если `RX Level` близок к максимуму, уменьшите TX или усиление RX и повторите калибровку.

## Дискриминация

Железный сектор по умолчанию: `-30°...+10°`.

- `выкл.`: сигнал звучит без дискриминации;
- `мягкий`: звук в железном секторе ослабляется до 20%;
- `жесткий`: звук в железном секторе выключается.

Реальная граница железо/цветной металл зависит от катушек, задержки аудиоадаптера, грунта и внешнего усилителя, поэтому сектор нужно подбирать экспериментально.
